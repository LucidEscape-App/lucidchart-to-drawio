How to export VSDX and JSON from Lucidchart

LucidEscape needs two exports from the same Lucidchart document: the JSON file and the VSDX file. Here is how to get both.

1
Open the document
In Lucidchart, open the diagram you want to move to draw.io.
2
Export as VSDX
File → Export → VSDX. Save the .vsdx file.
3
Export as JSON
File → Export → JSON. Save the .json file.
4
Upload both files
Return to the converter, drop in the matching .json and .vsdx pair, and get an editable draw.io file back.

FAQ

What do I need to get started?

The JSON and VSDX exports of a Lucidchart diagram — you'll need a Lucidchart account to create them. Export both from the same document (File → Export), then upload them here. LucidEscape never asks for your Lucidchart login.

Are my files kept private?

Files are processed on our own servers and never sent to third-party APIs. Anonymous previews are deleted within 24 hours.

What does it cost?

1 credit converts 1 diagram. Buy a credit pack when you need one — no subscription required.

Will the diagram stay editable?

Yes. Connectors, groups, labels and layout survive, so you get a normal editable draw.io / diagrams.net file, not a flat image.

What if the conversion is wrong?

The preview is free, so you can check the result before paying. Unused credits from a pack are refundable within 14 days — see our refund policy.
